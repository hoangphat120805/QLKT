## 🎯 Mục đích Tài liệu

Tài liệu này được tạo để:

- **Báo cáo**: Tổng hợp đầy đủ thông tin về hệ thống QLKT
- **Hướng dẫn**: Chi tiết từng loại khen thưởng, điều kiện, quy trình
- **Tham khảo**: Tài liệu kỹ thuật cho developers và stakeholders
- **Bảo trì**: Tài liệu cập nhật cho việc bảo trì và phát triển hệ thống

---

## 📊 Cấu trúc Tài liệu

Mỗi file tài liệu loại khen thưởng bao gồm:

1. **Tổng quan**: Mô tả loại khen thưởng
2. **Điều kiện**: Điều kiện đủ để được khen thưởng
3. **Quy trình**: Quy trình đề xuất và phê duyệt
4. **Cấu trúc Dữ liệu**: Schema database và JSON
5. **API Endpoints**: Các API liên quan
6. **Ví dụ**: Ví dụ cụ thể về đề xuất
7. **Lưu ý**: Các lưu ý quan trọng
